# KUMO: photo prompts

The site works without photos: each slot shows a shoji-and-cloud panel until a file with the matching name is placed in `src/assets/images/` (jpg, png or webp). After that, run `npm run build`.

Shared style for every prompt: *editorial Japanese restaurant photography, warm washi-cream background (#F3EDE2), vermilion red accents (#D33B24), soft natural window light, light wood, calm and minimal, shallow depth of field, shot on 35mm, no text, no logos, no people's faces.*

| File name | Where it shows | Ratio | Prompt |
|---|---|---|---|
| `villa-dining.jpg` | Story section, beside "Welcome to Kumo" | 4:5 | A calm dining room inside a reimagined 1980s Dubai villa styled like a Kyoto home: pale oak tables, shoji lattice screens, a paper lantern glowing softly, late-afternoon light, one table set with ceramic plates and a matcha cup, + shared style |
| `villa-facade.jpg` | The villa, large tile | 4:3 | The exterior of a low white 1980s villa on a palm-lined Dubai street at golden hour, a small red noren curtain at the entrance, warm light from shoji-screened windows, + shared style |
| `sushi-counter.jpg` | The villa, top-right tile | 4:3 | A light-wood sushi counter seen from a seat, a chef's hands in a red headband placing salmon nigiri on a ceramic plate, glass display of fish, + shared style |
| `matcha-bar.jpg` | The villa, bottom-right tile | 4:3 | A glowing matcha bar counter: bamboo whisk, chawan bowls, a tall iced matcha with a thick white salted-vanilla cream cloud on top, green and cream tones against red tiles, + shared style |
| `og.jpg` | Link preview image when the site is shared | 1.91:1 (1200×630) | Overhead flat lay on cream linen: signature nigiri, a kumo maki roll, an egg sando cut in half and a salted vanilla cloud matcha, red chopsticks, + shared style |

When KUMO approves the site, swap these for their own photography (Instagram @kumo.uae has strong red food shots) using the same file names.
